Timez

A native employee-activity monitoring app used by 300+ people at Webandcrafts.

WebandcraftsElectron.js desktop app300+ daily users

The problem

Webandcrafts needed native employee-activity tracking that runs reliably on Mac, Windows and Linux, keeps accurate time, and doesn't lose data when a machine sleeps or shuts down unexpectedly.

What I built

  • Real-time time sync between the app and the server.
  • System tray integration and the in-app timer.
  • Sleep handling, so tracking pauses and resumes correctly when a machine sleeps.
  • Application behaviour logging with electron-log.
  • Per-user cron scheduling for background jobs.
  • A recovery mechanism that preserves user data through unexpected shutdowns and crashes.

Results

  • Used daily by 300+ people.
  • Per-user cron scheduling cut server load by ~70% and improved stability.
